Agents Anywhere · Windows 10 Mobile 界面设计稿 v3

按 Windows 10 Mobile 的设计语言重做。画板 360 × 640 有效像素（Lumia 950 竖屏），包含顶部状态栏和底部系统导航栏。数据都是示意。图标使用 Segoe MDL2 Assets，与 UWP 的 FontIcon / SymbolIcon 对应。点击“过程”标题、思考或工具步骤可以展开或折叠。

强调色跟随系统设置，下面可以切换预览：

Windows 10 Mobile 设计规则对照

  • 颜色：纯黑背景，强调色读 SystemAccentColor，不写死品牌色。界面上只用 Windows 的系统色：警告黄 #FFB900、错误红 #E81123、成功绿。
  • 形状：全部直角，没有圆角卡片和阴影。层级靠灰阶背景区分：#000、#171717、#1F1F1F、#2B2B2B。
  • 文字：Segoe UI / 微软雅黑 UI。页面大标题用细体（Light / SemiLight），正文 15px，次要信息用 60% 白。
  • 导航：根页面和会话页都用 Pivot，可以左右滑动切换。不在页面里放返回箭头，统一用系统返回键。
  • 命令：底部 CommandBar，只放图标，点 ••• 后展开文字标签和次要命令。会话页用最小化的 CommandBar，把空间留给消息。
  • 对话框：审批等重要决定用 ContentDialog，在手机上贴顶全宽显示，两个等宽按钮。
  • 进度：运行中用飞点进度条，单项用点状 ProgressRing。实时连接中断时，在状态栏显示 StatusBar.ProgressIndicator 的文字和飞点。
  • 控件：TextBox 和 ComboBox 使用 2px 边框，TextBox 获得焦点时变白底。ComboBox 在手机上打开全屏选择页。

一轮 Agent 循环怎么排

  1. 一轮从一条用户消息开始，到 turn.end 或下一条用户消息为止。除最终输出外的条目，都按时间顺序串在同一条过程轨道上。思考和工具交替多少次，轨道都只有一条。
  2. 已完成的轮收成一行摘要；有失败或被打断时默认展开。运行中的轮保持展开，只显示最近 5 步，更早的步骤收成“显示前面 n 步”。
  3. 运行中如果最后一条回复后面又出现工具，它会收进轨道，变成中间说明。
