Agents Anywhere · Windows 10 Mobile 界面设计稿 v2

原生 UWP（C# + XAML，最低 14393）手机端重做方案。画板按 360 × 640 有效像素（Lumia 950 / 950 XL 竖屏）绘制，顶部 24px 为系统状态栏。所有数据都是示意。图标使用 Segoe MDL2 Assets，与 UWP 里的 FontIcon / SymbolIcon 一一对应。点击“过程”标题、思考或工具步骤可以展开或折叠。

时间线条目怎么区分

类别视觉规则数据来源（上游 timeline item）默认状态
用户消息唯一靠右的气泡，薄荷色底。附件在气泡下方。发送中为虚线边框，失败时显示“重试”（复用同一 clientMessageId）。type=message，role=user完整显示
推理过程轨道上的紫色圆形节点。小号灰色斜体，没有背景。标签写“思考 · 用时”。type=system，content.kind=reasoning，读 summaries[] / rawText两行预览，点开看全文；正在进行的思考实时展开
工具调用过程轨道上的蓝色方形节点，按工具种类换图标。等宽目标文字，右侧是状态（转圈 / 勾 / 叉），失败时节点变红。点击查看命令输出或 diff。type=tool，按 content.kind 选图标：command、file_change、web_search、mcp、agent_call、tool_call；type=artifact 同样处理只显示一行；失败或运行中的工具展开输出
中间说明过程轨道上的薄荷色小圆点，正常字色、14px、不斜体。是 Agent 在两次工具之间说的话。role=assistant 的 message，且同一轮里它后面还有思考或工具完整显示
输出本轮最后一条回复，放在过程轨道外面。左对齐通栏正文，不加气泡，15px 大字。支持段落、列表、行内代码和可横向滚动、可复制的代码块。下方显示用时。role=assistant 的 message，且后面没有思考或工具；turn.end 只用来显示“已完成 · 用时”完整显示；超过 40 行时折叠到“展开全文”
审批 / 输入请求待处理时是轨道之后的琥珀色卡片，永远不会被折叠。卡片只给摘要和“查看详情”，决定在底部面板里做；复杂 schema 打开整页表单。处理后变成轨道里的琥珀色方形节点。open notices（/runtime/notices/{id}/respond）始终显示，列表中带“需要你处理”标记
系统 / 错误居中细分隔线文字（压缩上下文、日期、被打断）。错误用浅红卡片。type=marker、type=system（非 reasoning）、status=failed完整显示

一轮 Agent 循环怎么排（见 03、04、04-A、04-B）

  1. 一轮从一条用户消息开始，到 turn.end 或下一条用户消息为止。
  2. 一轮里除最终输出之外的所有条目（思考、工具、中间说明、已处理的审批）按时间顺序串在同一条过程轨道上。思考和工具交替多少次都只有一条轨道，不会拆成很多小卡片。
  3. 节点形状区分类型：圆形是思考，方形是工具，小圆点是中间说明，琥珀方块是审批；颜色只是辅助。
  4. 最终输出是本轮最后一条、后面没有思考或工具的 assistant 消息，放在轨道外用大字显示。运行中如果它后面又出现了工具，它就收进轨道，变成中间说明；位置几乎不动，只是多了缩进。
  5. 已完成的轮：轨道收成一行摘要（思考数 · 工具数 · 失败数 · 用时）。有失败或被打断时默认展开。
  6. 运行中的轮：轨道展开，只显示最近 5 步，更早的收成“前面 n 步”。正在进行的那一步实时展开；结束后自动收回预览。
  7. 待处理的审批放在轨道后面，不跟随折叠。处理后变成轨道里的节点，记录你的决定和时间。
