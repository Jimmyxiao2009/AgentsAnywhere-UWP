## 设计决定

1. 工作区：项目选择、搜索和最近会话；状态同时有文字与颜色。主导航为会话、设备、我的，新建会话置于底部。
2. 会话：详情页隐藏主导航；工具集中到右上菜单。代码和工具结果可折叠，输入区固定，支持附件、发送、停止、追加指令。
3. 审批：会话内提示进入独立确认页，分别展示操作、目标、设备和范围。允许一次 / 拒绝固定在底部。
4. 设置：运行偏好、工作环境与会话工具分组。文件和终端进入单独页面。
5. 深色背景 #101821；强调 #62E1BD；待确认 #E8BA73。正文16、标题18–22、元数据12。页面边距20，主要触控目标48。
6. 保留 Windows 系统状态与返回导航的视觉位置；实际 UWP 接入系统栏，不能重复绘制模拟系统栏。使用平台字体和可替换为原生图标的线性图标。

项目切换、新建、设备、我的、附件、文件和终端等入口有模拟页面或菜单。选择设置、上传、终端执行、复制、归档、改名等只提示演示，不代表功能实现。

## 原生重写要求

- 这份 HTML 不作为 WebView 产品。将布局转换为 UWP XAML 和独立视图状态，保留现有官方服务 / 登录 / 协议 / 隐私日志。
- 模型、推理、权限及快捷命令选项必须取运行时返回的数据，不能硬编码设计示例。
- 现有审批 schema 可能比单文件读取复杂。真实 UI 必须完整展示协议请求，不把所有请求简化成此示例。
- 实现时补齐登录失败、离线、空列表、重连、附件失败、键盘弹起、加载旧消息、复杂审批和文件编辑等真实状态。
- 应在设备192.168.3.159上测试实际键盘、系统返回、滚动位置、触控和实时状态。原型截图不替代真机验收。
